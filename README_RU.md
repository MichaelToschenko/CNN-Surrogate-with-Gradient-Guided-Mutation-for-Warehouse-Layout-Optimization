# CNN-аппроксимация с градиентно-направленной мутацией для оптимизации планировок склада

> Принято на **ICRAS 2026**. Приведённые ниже числа соответствуют camera-ready версии (10 сидов + ablation-исследование).

Проект решает задачу оптимального размещения точек входа, выхода и зон хранения на прямоугольной сетке автоматизированного склада. Качество конфигурации измеряется числом шагов дискретно-событийной симуляции, необходимых для обработки фиксированного числа контейнеров мобильными роботами. Реализованы два алгоритма: базовый генетический алгоритм (**GA**) и его модификация (**CNN-GA**), в которой свёрточная нейронная сеть выступает аппроксимацией функции пригодности - как для отбора кандидатов, так и в качестве источника градиента для направленной мутации.

## Процесс оптимизации

## Постановка задачи

- **Представление склада.** Прямоугольная сетка m×n, каждая ячейка - одного из 4 типов: `Road`, `Entry`, `Exit`, `Save`. Количество ячеек каждого типа задаётся параметрами и сохраняется на протяжении оптимизации.
- **Симуляция.** На каждом шаге в ячейках `Entry` с вероятностью `p` появляются контейнеры. Диспетчер назначает задачи роботам по принципу ближайшего свободного; маршруты строятся поиском в ширину по сети `Road`-ячеек. Контейнер проходит путь `Entry → Save → Exit`.
- **Целевая функция.** `T(x)` - число шагов симуляции, необходимых для обработки заданного количества контейнеров при конфигурации `x`. Задача - минимизировать `T(x)`.

## Метод

**GA (базовый).** Турнирная селекция, одноточечное горизонтальное/вертикальное скрещивание, relocation-мутация (перемещение не-Road ячейки на случайную Road-позицию), элитизм.

**CNN-GA.** Те же операторы, плюс два механизма на основе обученного CNN-суррогата `f̂_θ(X)`:

1. **Pre-screening.** Генерируется `α·(N−E)` кандидатов, суррогат предсказывает их пригодность, на симуляцию передаются только `N−E` лучших.
2. **Градиентно-направленная мутация.** Градиент `∇_X f̂_θ(X)` ранжирует возможные перемещения ячеек; top-T пар верифицируются полным прогоном суррогата, лучшая применяется.

Первые `n_a` поколений - фаза накопления обучающих данных (суррогат не используется). Далее суррогат дообучается каждые `r` поколений. **Бюджет симуляционных оценок у GA и CNN-GA одинаковый** - сравнение честное.

python -m venv .venv

## Запуск

Три entry-point'а (из корня проекта):

```bash
python -m experiments.comparison      # GA vs CNN-GA, 10 сидов - основные графики статьи (convergence.png, mean_fitness.png, ...)
python -m experiments.ablation        # Добавляет две модификации CNN-GA (PreOnly, GradOnly) на тех же 10 сидах и строит *_ablation.png
python -m experiments.evolution_viz   # Полоса снимков лучшей планировки по поколениям
```

Оба скрипта `comparison` и `ablation` работают на одном и том же множестве `SEEDS_10` и используют общие логи GA/CNN-GA в `logs/` (`ablation` их переиспользует, добавляя только два собственных прогона). Все скрипты переиспользуют кэшированные логи - чтобы пересчитать прогон с нуля, удалите соответствующий файл `run_*.json`.

Интерактивный пример:

```python
from algorithms import GeneticAlgorithm, CNNGuidedGA

ga = GeneticAlgorithm(
    m=15, n=15, entries=5, exits=5, saves=30,
    num_robots=12, containers_to_process=160, prob=0.35,
    pop_size=50, generations=80, n_jobs=-1,
)
best_config, log = ga.run()
best_config.plot()
```

## Результаты

**Условия эксперимента:** сетка 15×15, 5 входов / 5 выходов / 30 ячеек хранения, 12 роботов, 160 контейнеров, `p=0.35`. Параметры эволюции: `N=50`, `G=80`. По 10 прогонов с сидами `{42, 123, 456, 789, 1337, 2024, 31337, 9001, 271828, 161803}`.

### Ablation-исследование

![Ablation: средняя пригодность популяции](plots/mean_fitness_ablation.png)

Изолированный вклад каждой суррогатно-управляемой компоненты (10 прогонов) даёт ясную картину. Cлишком жёсткий отбор суррогатом схлопывает разнообразие популяции, и случайная relocation-мутация не позволяет выйти из получившегося локального оптимума - видно по рано выходящей на плато зелёной кривой выше. **Только градиентная мутация сопоставима с полным CNN-GA** - именно она является доминирующим источником улучшения. Pre-screening сохранён в итоговой модели, поскольку не расходует бюджет симуляций и служит независимым подстраховочным механизмом в первых поколениях после активации суррогата, когда R² ещё нестабилен.

### Качество суррогата

![R² суррогата](plots/cnn_surrogate_r2.png)

Коэффициент детерминации `R²` суррогата по циклам дообучения. После нескольких первых циклов с высокой дисперсией выходит на уровень ≈0.95 - предсказания близки к истинным значениям, что объясняет информативность градиентного сигнала для мутации.
